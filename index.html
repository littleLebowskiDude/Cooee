History

Everything you have dictated, newest first. Copy one if it landed in the wrong place.

    Model

    A file is a whisper.cpp GGML model such as ggml-base.en.bin (141 MB) from huggingface.co/ggerganov/whisper.cpp, run on the CPU. A folder is an ONNX export such as onnx-community/whisper-small.en, run with the encoder on the NPU. Loads in the background when you save.

    Fewer is faster on a busy machine. Leave blank unless you have measured.

    Dictating

    The third tone is lower and longer than the other two. Without it a dictation that produced nothing sounds exactly like one that worked.

    Insertion

    Focus another app within 3 seconds to see where the text lands.

    Per-app insertion

    No single strategy works everywhere. Some Electron apps drop synthesised keystrokes and want a paste; fields that refuse a paste want the keystrokes. Name an executable here to override the strategy above for that app only. Everything not listed keeps using it.

    Click, then focus the app you want a profile for. Saves you having to know what its executable is called.

      Dictionary

      Words the model keeps getting wrong. The corrections are applied to every transcript, and the right-hand spellings are also shown to the model before it listens, so it usually gets them first time.

        Your data

        Everything Cooee holds is on this machine, in the folder below. Nothing is sent anywhere — the binary has no HTTP client and no TLS stack compiled into it, so there is nothing in it that could originate a request. Run tools\no-network.ps1 to check that against the real dependency tree rather than taking it on trust.

        Transcripts are stored as plain JSON, so treat the folder the way you would treat the documents you dictated.
